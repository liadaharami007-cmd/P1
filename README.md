# P1 AI

מרכז ההמרות של החנות שלך: P1 נכנס לחנות בדפדפן אמיתי (מחשב וטלפון), עובר את מסע הרכישה עד הקופה,
מתעד כל מכשול בצילומי מסך, מריץ סימולציה של 5 סוגי לקוחות, ומפיק דוח עם ציון, בעיות לפי חומרה ותוכנית תיקון.

## הפעלה מהירה
```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium
uvicorn app.main:app --reload --port 8000
```
פתחו http://localhost:8000 והכניסו כתובת חנות.

- **בדיקות אתר, לקוחות מדומים, לוח בקרה ומשימות** — עובדים בלי שום מפתח.
- **עוזר AI** — דורש `ANTHROPIC_API_KEY` בקובץ `.env` (ראו `.env.example`). בלעדיו הוא מושבת ואומר זאת.

> ⚠️ אין עדיין מערכת משתמשים. אל תעלו את השרת לאינטרנט הפתוח במצב הזה.

## בדיקות

python -m pytest -q
